# Music-Store-Database-Analysis-
Data analytics project showcasing Music Store database analysis using  SQL 

Overview
This project analyzes a music store database using SQL to uncover insights that drive business decisions.We will work with real-world data such as customers, invoices, artists, and tracks. Each query answers a specific business question and demonstrates practical SQL skills.
The project progresses from basic queries to advanced analysis.

Dataset
The dataset simulates a digital music store and includes:
Customers
Employees
Invoices and invoice lines
Tracks, albums, artists
Genres

Problem Sets 
Easy Level — Foundation
Build confidence with core SQL concepts:

Identify the senior-most employee
Find countries with the most invoices
Detect highest invoice totals
Determine the best-performing city
Identify the top customer by total spend

These queries focus on:SELECT, ORDER BY, GROUP BY, LIMIT

Moderate Level — Deeper Analysis
Move into more structured data exploration:

List all Rock music listeners with contact details
Find top 10 rock artists by track count
Identify tracks longer than the average duration

These queries introduce:JOIN,HAVING,Subqueries,Aggregations

Advanced Level — Business Intelligence   
Solve complex, real-world scenarios:

Calculate how much each customer spends on each artist
Identify the most popular genre by country
Find the top-spending customer in each country

These queries demonstrate:Advanced joins,Nested queries,Window functions (optional but recommended)

Key Insights You Can Extract
Who drives the most revenue
Where your strongest markets are
What music customers actually buy
How purchasing behavior varies by region

Tools & Skills
SQL (SQLite / PostgreSQL / MySQL)
Data analysis
Relational database design
Business thinking
